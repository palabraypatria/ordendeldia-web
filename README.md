# Orden del Día

Web de versículo del día, santo del día y efemérides de España y del Ejército.

## Estructura

- `index.html` — aplicación principal
- `netlify.toml` — configuración de Netlify

## Despliegue

1. Este repositorio se despliega automáticamente en Netlify
2. El proxy de la API está en Railway
3. El dominio apunta a Netlify vía DNS en Hostalia
